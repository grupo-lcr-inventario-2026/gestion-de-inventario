Quiénes Somos

Somos el Grupo LCR, un equipo de estudiantes que desarrolla este Sistema de Gestión de Inventario como parte de la materia Full Stack I.

El proyecto busca ordenar la información de productos y stock con una estructura simple, clara y fácil de consultar.

Propósito del Proyecto

El propósito es mostrar un sistema básico de inventario con organización de productos, stock y roles de usuario.

Se desarrolla como práctica académica usando HTML, CSS y Bootstrap.
