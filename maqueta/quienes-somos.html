Quiénes Somos

Somos el Grupo LCR, un equipo de estudiantes que desarrolla este Sistema de Gestión de Inventario como parte de la materia Full Stack I.

El proyecto apunta a ordenar la información de productos y stock con una estructura simple, clara y fácil de consultar. Buscamos representar una solución académica prolija, con una lógica cercana a la de un sistema de uso cotidiano.

Propósito del Proyecto

El propósito de este proyecto es mostrar, de forma ordenada y sencilla, cómo podría organizarse un sistema básico para administrar inventario. La maqueta reúne las secciones principales para consultar productos, controlar stock y separar accesos según el rol de cada usuario.

También nos permite poner en práctica lo trabajado en la materia Full Stack I, usando HTML, CSS y Bootstrap como base de desarrollo. Buscamos una presentación clara, prolija y cercana a una herramienta real de uso diario.
