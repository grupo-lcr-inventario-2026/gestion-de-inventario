Quiénes Somos

Somos el Grupo LCR, encargado del desarrollo del proyecto Sistema de Gestión de Inventario para la materia Full Stack I.

Este sistema fue creado con el objetivo de mejorar la organización, administración y control del stock de productos dentro de una empresa.

Propósito del Proyecto

Este sistema resuelve la necesidad de organizar y controlar el inventario de una manera simple y clara. Está pensado para la materia Full Stack I, como parte del trabajo práctico del grupo. El proyecto se desarrolló con HTML, CSS y Bootstrap, manteniendo una estructura básica y fácil de entender. Su objetivo es mostrar cómo administrar productos, stock y accesos con una interfaz ordenada.
